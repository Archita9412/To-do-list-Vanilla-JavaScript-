# To-Do List (Vanilla JavaScript)

A clean, responsive, and fully functional To-Do List application built using HTML, CSS, and Vanilla JavaScript. This project demonstrates core front-end development concepts without relying on external libraries or frameworks.

---

## Features

* Add new tasks
* Delete existing tasks
* Mark tasks as completed
* Persistent data storage using localStorage
* Clean and responsive user interface
* Lightweight and fast (no external dependencies)

---

## Tech Stack

* HTML5 – Structure
* CSS3 – Styling and layout
* JavaScript (Vanilla) – Application logic and interactivity

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/To-do-list-Vanilla-JavaScript.git
```

### 2. Navigate to the Project Directory

```bash
cd To-do-list-Vanilla-JavaScript
```

### 3. Open in Browser

Simply open the `index.html` file in your browser.

---

## How It Works

* Tasks are added via an input field and stored in localStorage.
* Each task can be marked as completed or deleted.
* On page reload, tasks are retrieved from localStorage to maintain persistence.
* JavaScript dynamically updates the DOM for real-time interaction.
